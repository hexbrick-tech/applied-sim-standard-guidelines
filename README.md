# Applied SIM Standard Guidelines

**Standard guidelines defining the semantic interface between SIM Foundation and Applied SIM practices.**

This repository defines the normative requirements that an Applied SIM practice follows when applying concepts and semantics from SIM Foundation.

The guidelines do **not** prescribe a single workflow, domain model, tool, or AI implementation. They define the semantic constraints that Applied practices must preserve while remaining free to choose their own procedures.

## Current draft

- [Applied SIM Standard Guidelines v0.1](docs/applied-sim-standard-guidelines-v0.1.md)

## Position

```
SIM Foundation
      |
      | semantics / invariants
      v
Applied SIM Standard Guidelines
      |
      | conformance contract
      v
Applied SIM practices
```

An Applied SIM practice may declare conformance to a specific version of these guidelines.

## Status

Draft. The initial version is being developed from observed application behavior and will be cross-reviewed against SIM Foundation for semantic consistency and traceability.
